# AVA-IA

Ambiente Virtual de Aprendizagem com suporte de Inteligência Artificial.

## 🚀 Objetivo

Desenvolver uma plataforma web capaz de auxiliar estudantes durante o aprendizado utilizando IA para gerar explicações, resumos e exercícios.

## 🧠 Funcionalidades

* Plataforma de cursos
* Assistente com IA
* Resumos automáticos
* Geração de exercícios
* Explicações personalizadas

## 🛠️ Tecnologias

* Next.js (Frontend)
* Django REST (Backend)
* API de IA
